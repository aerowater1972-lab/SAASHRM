## 2. API Key Management Test Cases

| # | Test Case | Steps | Expected Result |
|---|-----------|-------|-----------------|
| OA-02-01 | Generate API Key | 1. Login 2. Go to API Keys 3. Click Generate | API key generated, key shown once |
| OA-02-02 | Revoke API Key | 1. List keys 2. Select key 3. Click Revoke | Key inactive, cannot be used |
| OA-02-03 | Rate Limit Per Tenant | 1. Have 10 keys 2. Generate 11th | Error: limit reached |
| OA-02-04 | Verify API Key | 1. Use valid key | Access granted |
| OA-02-05 | Invalid API Key | 1. Use wrong key | Access denied |
| OA-02-06 | List API Keys | 1. GET /api-keys | Keys listed with prefix only (full key never redisplayed) |
| OA-02-07 | Update API Key | 1. Rename key / change expiry | Changes saved and reflected in list |
| OA-02-08 | Scope Enforcement | 1. Use key limited to `slack:write` on another scope | Access denied (403) |
| OA-02-09 | Delete API Key | 1. DELETE /api-keys/:id | Key removed permanently, subsequent calls fail |
| OA-02-10 | Expired API Key | 1. Use key past `expiresAt` | Access denied |
