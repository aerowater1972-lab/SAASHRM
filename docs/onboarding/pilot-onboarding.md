# Pilot Onboarding Program

**Version: 1.0 | October 2026**

## Program Overview

**Objective**: Validate Flexy HRMS with 3-5 pilot companies before public launch
**Duration**: 8 weeks (2 weeks setup + 6 weeks active use)
**Success Criteria**: 
- 80% feature adoption
- <5 critical bugs
- NPS > 8
- Zero data loss incidents

---

| Criteria | Requirement |
|----------|-------------|
| Size | 50-500 employees |

## Onboarding Timeline (8 Weeks)

### Week 1-2: Setup & Configuration
| Day | Activity | Owner | Deliverable |
|-----|----------|-------|-------------|
| 1-2 | Kickoff call + requirements gathering | CSM + Pilot Team | Signed scope |
| 3-4 | Environment provisioning (tenant, SSO, domain) | DevOps | Access credentials |
| 5-6 | Company setup (org, leave, attendance, payroll config) | CSM + Pilot Admin | Configured tenant |
| 7-8 | Data migration (employees, leave balances, payroll history) | CSM + Pilot Team | Migrated data |
| 9-10 | Integration setup (bank, email, Slack/Teams) | DevOps + Pilot IT | Working integrations |
| 11-12 | User acceptance testing (core flows) | Pilot Team | UAT sign-off |
| 13-14 | Go-live preparation (parallel run plan) | CSM + Pilot Team | Go-live plan |

### Week 3-8: Active Pilot
| Week | Focus | Success Metrics |
|------|-------|-----------------|
| 3-4 | Core HR + Leave + Attendance | 100% employees onboarded, 90%+ leave requests digital |
| 5-6 | Payroll (parallel run) | Payroll matches manual calc ±1% |
| 7-8 | Full workflow + Reporting | All modules active, reports generated |

## Go/No-Go Criteria (Week 8)

| Criterion | Threshold |
|-----------|-----------|
| Feature Adoption | >80% employees using core features |
| Data Accuracy | Payroll matches manual ±1% |
| Critical Bugs | Zero P1/P2 open |
| User Satisfaction | NPS > 8 |
| Support Tickets | <5 P1/P2 per week |
| Performance | p95 < 500ms |

**Go Decision**: All criteria met → Proceed to contract
**No-Go**: Remediation plan + extended pilot (4 weeks)
