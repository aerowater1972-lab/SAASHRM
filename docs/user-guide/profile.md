# Profile & Settings

## Personal Information

### Editable (Self-Service)
- ✅ Full Name
- ✅ Phone Number
- ✅ Personal Email
- ✅ Address (KTP & Domisili)
- ✅ Emergency Contact
- ✅ Profile Photo

### Requires HR Approval
- 🔒 Bank Account
- 🔒 NPWP (Tax ID)
- 🔒 BPJS Numbers
- 🔒 Religion, Blood Type, Marital Status
- 🔒 Education, Certificates

**How to Request**: Edit field → Submit → HR reviews → Approved/Rejected with reason

## Security Settings

### Password
- **Change**: Profile → Security → Change Password
- **Policy**: Min 8 chars, 1 upper, 1 lower, 1 number, 1 symbol
- **History**: Last 5 passwords blocked

### Two-Factor Authentication (2FA)
1. Profile → Security → **Enable 2FA**
2. Scan QR with Authenticator (Google/Microsoft/Authy)
3. Enter 6-digit code → **Enable**
4. **Recovery Codes**: Save 10 codes (shown once!)

### Sessions
- View active devices/locations
- **Revoke All**: Logout everywhere
- Auto-expire: 30 days inactivity

## Data Export (GDPR/PDP)

**Profile → Privacy → Export My Data**
- Formats: JSON, PDF, CSV
- Includes: All personal data, leave, attendance, payroll, documents
- Generated within 24h, link expires 7 days

## Account Deletion

**Profile → Privacy → Delete Account**
- Requires: Password + 2FA + HR approval
- **Irreversible**: All data anonymized (GDPR Art. 17)
- Retention: Audit logs 7 years (legal requirement)
