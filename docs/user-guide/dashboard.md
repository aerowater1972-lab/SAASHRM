# Dashboard Overview

The dashboard is your command center. Here's what each widget shows:

## Widgets

| Widget | Description | Refresh |
|--------|-------------|---------|
| **My Leave Balance** | Remaining days by type (Annual, Sick, etc.) | Real-time |
| **Upcoming Leave** | Your approved leave in next 30 days | Real-time |
| **Attendance This Month** | Present, Late, Absent, WFH counts | Daily 6 AM |
| **Payslip Summary** | Latest net pay, YTD earnings | Monthly |
| **Pending Approvals** | Items awaiting your action | Real-time |
| **Team Calendar** | Team leave next 30 days (managers) | Real-time |

## Customizing Your Dashboard

1. Click **⚙️ Customize** top-right
2. Drag widgets to reorder
3. Toggle visibility per widget
4. Click **Save Layout**

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Alt + D` | Go to Dashboard |
| `Alt + L` | Leave Request |
| `Alt + A` | Attendance Clock In |
| `Alt + P` | Payslips |
| `/` | Global Search |
| `?` | Keyboard Shortcuts Help |
