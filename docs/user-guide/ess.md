# Employee Self-Service (ESS)

Access all your HR needs in one place.

## Modules

### 📅 Leave Management
- **New Request**: Select type, dates, reason, attachment
- **My Requests**: Track status (Pending/Approved/Rejected)
- **Balance**: Real-time remaining days per type
- **Calendar View**: Visual overview of your leave

### ⏰ Attendance
- **Clock In/Out**: GPS + selfie verification (configurable)
- **History**: Filter by date, status, location
- **Corrections**: Request fix for missed clock
- **WFH Request**: Submit work-from-home schedule

### 💰 Payroll
- **Payslips**: Download PDF, view breakdown
- **Tax (PPh 21)**: Monthly & annual calculation
- **BPJS**: Contribution history
- **Annual Tax (1721-A1)**: Download form

### 💳 Expense Claims
- **New Claim**: Category, amount, receipt photo
- **Policy**: Auto-validated against company rules
- **Reimbursement**: Track to bank transfer

### 📋 Profile & Documents
- **Personal Info**: Editable fields + approval workflow
- **Documents**: Upload KTP, NPWP, Ijazah, SKCK, etc.
- **Certificates**: Generate employment, salary, experience letters
- **Emergency Contact**: Manage ICE info

### 🔔 Notifications
- **In-app**: Real-time bell icon
- **Email**: Critical actions (approvals, payroll)
- **Push**: Mobile (if PWA installed)
