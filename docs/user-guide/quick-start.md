# Quick Start Guide

Welcome to Flexy HRMS! This guide will help you get started in 15 minutes.

## 1. First Login

1. Open your company's Flexy HRMS URL (e.g., `https://yourcompany.flexy-hrms.com`)
2. Enter your corporate email and password
3. Complete MFA setup if prompted (recommended)

## 2. Complete Your Profile

Navigate to **Profile → My Profile** and verify:
- ✅ Personal info (name, phone, address)
- ✅ Emergency contact
- ✅ Bank account (for payroll)
- ✅ Tax ID (NPWP)
- ✅ BPJS numbers (Kesehatan & Ketenagakerjaan)

## 3. First Actions by Role

### Employee (ESS)
| Action | Location |
|--------|----------|
| Request leave | **Leave → New Request** |
| Clock in/out | **Attendance → Clock In** |
| View payslip | **Payroll → Payslips** |
| Submit expense | **Expense → New Claim** |

### Manager
| Action | Location |
|--------|----------|
| Approve leave | **Leave → Pending Approval** |
| View team calendar | **Leave → Team Calendar** |
| Approve expense | **Expense → Pending Approval** |
| View team attendance | **Attendance → Team View** |

### HR Admin
| Action | Location |
|--------|----------|
| Add employee | **Employees → New Employee** |
| Configure leave types | **Leave → Settings → Leave Types** |
| Run payroll | **Payroll → Runs → New Run** |
| Manage organization | **Organization → Structure** |

## 4. Mobile Access

Flexy HRMS is fully responsive. Add to home screen for app-like experience:
- iOS: Safari → Share → Add to Home Screen
- Android: Chrome → Menu → Add to Home Screen
