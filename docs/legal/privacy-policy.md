## 5. Data Security

### Technical Measures
- Encryption at rest: AES-256-GCM (salary, PII)
- Encryption in transit: TLS 1.3
- Passwords: bcrypt (cost 12)
- JWT: RS256, 15min access, 7d refresh (rotating)

### Infrastructure
- AWS Jakarta (primary), Google Cloud Singapore (DR)
- VPC, Security Groups, WAF
- ISO 27001 certified (certified 2024)
- Annual 3rd-party pen test

### Access Control
- Role-based (RBAC) + Attribute-based (ABAC)

### Incident Response

- Incident response plan (tested quarterly)
- Notification: 72h (GDPR), 72h (UU PDP)
